요청 ⑧

입력 시작
현재 사업기획서를 검토만 해 줘.
①고객·문제의 구체성 ②서비스·가치의 연결 ③차별점의 근거 ④수익·비용·효과의 가설 표시 ⑤4주 실행·확인 가능성 ⑥담당자 검토와 서비스 제외 범위를 살펴봐 줘.
중요한 항목 최대 5개를 ‘문제 문장/확인할 이유/수정 제안’으로 보여 줘. 없는 오류나 수치·실적을 만들지 마.
지금은 Canvas를 고치지 말고 내가 반영할 항목을 선택할 때까지 기다려 줘.
입력 끝

요청 ⑨

입력 시작
아래에서 내가 선택한 수정사항만 현재 Canvas에 반영해 줘.
선택하지 않은 문단·출처·[가설] 표시·교육용 가상사례 표시는 유지해 줘. 담당자 검토와 자동 발송·주문 조회·환불·보상 판단 제외도 유지해 줘.
새 수치·실적을 넣지 말고, 수정 후 바뀐 문장과 변경 이유만 짧게 보여 줘.
선택사항: [실제 검토의 항목 번호와 내가 정한 수정 방향]
입력 끝

----------------------------------------
요청 ⑩  (필요할 때만)

입력 시작
필요할 때만: 내가 선택한 아래 두 문제만 현재 문서에서 고쳐 줘.
유료 이용 의향을 단정한 문장은 ‘아직 확인하지 않은 가설’로 바꿔 줘. 차별점은 ‘초기 안내문 정리와 담당자 검토를 함께 지원하는 운영 방식’이라는 검증할 제안으로 써 줘.
다른 문단·확인된 출처·가설 표시는 유지하고 새 수치·실적은 넣지 마. 바뀐 문장만 짧게 알려 줘.
