검토를 마친 현재 보고서만으로 8장 발표 원고를 별도로 써 줘.
순서: ①사업 제안 ②대상 고객과 문제 ③제공 서비스 ④유사 서비스와 검증할 차별점 ⑤운영·수익 방식 가설 ⑥4주 시범 운영 ⑦확인할 지표와 위험 ⑧결정 요청.
각 장은 짧은 제목·핵심 문장 1개·본문 최대 3개로 해 줘. 출처·가설·교육용 가상사례 표시·서비스 범위를 유지해 줘.
새 수치·실적을 넣지 말고 최종 보고서 본문은 바꾸지 마.

아래 확정 원고로 동료에게 설명할 한국어 발표자료 8장을 만들어 줘. 먼저 원고 순서대로 8장 구성 계획을 보여 줘.
한 장에 핵심 하나, 큰 글자와 짧은 문장을 써 줘. 먼저 글과 기본 배치만 만들고 이미지는 새로 생성하지 마. 고객·제공물·범위·4주 기간·출처·가설 표시를 유지해 줘.
새 조사·주장·숫자를 추가하지 말고 실제 고객 로고나 구현 완료 화면을 만들지 마. 교육용 가상사례임을 표시해 줘.
확정 원고: [검토한 8장 발표 원고 전체]

2차시 · 7단계 · 이미지·배치·글 고치기  (Gamma)
==================================================

요청 ⑬  (필요할 때만)

입력 시작
작은 온라인 판매점 담당자가 반복 문의를 정리하고 답변 초안을 검토하는 단순한 평면 일러스트를 만들어 줘.
문의 카드·정리된 안내문·사람이 검토하는 모습이 보이게 해 줘. 밝은 배경, 파랑·회색, 가로형 발표자료에 어울리는 구성이면 돼.
읽을 수 있는 글자·숫자·로고·실제 고객정보는 넣지 마. 실제 고객센터 화면이나 구축 완료된 서비스처럼 보이지 않게 해 줘.
설명용 이미지만 만들고 슬라이드 글과 레이아웃은 바꾸지 마.
입력 끝

요청 ⑭

입력 시작
선택한 3장 ‘제공 서비스’ 카드만 왼쪽 텍스트, 오른쪽 설명용 이미지의 2열로 바꿔 줘. 이미지가 없으면 오른쪽에 담당자 검토·제외 범위를 놓아 줘.
기존 제목·핵심 문장과 FAQ 정리·답변 초안·안내문 갱신을 읽기 쉽게 배치해 줘.
담당자 검토와 서비스 제외 범위를 포함해 기존 문장·숫자·출처·가설·교육용 가상사례 표시는 바꾸거나 삭제하지 마.
기존 이미지의 내용과 다른 카드는 그대로 유지해 줘.
입력 끝

요청 ⑮

입력 시작
선택한 8장 ‘결정 요청’의 글만 제목 한 줄과 본문 두 문장으로 짧게 고쳐 줘.
‘가상 시범 고객 한 곳을 대상으로 4주간 서비스 운영 방식과 유료 이용 의향을 검토하자’는 요청이 보이게 해 줘.
검증되지 않은 성공·매출·절감 효과를 말하지 마. 기존 출처·가설·교육용 가상사례 표시는 유지해 줘.
이미지·레이아웃·다른 카드는 바꾸지 마.
