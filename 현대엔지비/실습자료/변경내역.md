# 실습 자료 변경 내역

원본 패키지(고객 문의 개선계획 + 선적서류 시연 + NotebookLM 선택)를 **요청서 차시 구성**과 **PPTX 교안(엔지비기업 FAQ 서비스 기획)**에 맞춰 다시 구성했습니다. 기초 과정이므로 단계마다 "이번에 할 일 → 따라 하기 → 복사할 요청 → 이렇게 나오면 성공 → 안 되면"만 남기고 쉽게 썼습니다.

## 5차 정리 (파일 받기 · Gamma 대안)

- 실습가이드.html 안에 장별 파일 4개를 넣고 「받기」 버튼을 달았습니다. HTML 하나만 받아도 파일을 받을 수 있고, 온라인 가이드에서도 확인 창을 거쳐 받을 수 있습니다.
- 6장에 「Gamma가 안 될 때」를 추가했습니다: 1순위 미리캔버스 AI 프레젠테이션(실제 화면 캡처와 핀 순서), 2순위 Kimi 슬라이드, 마지막 PowerPoint·Google Slides 직접 작성. 7장에 미리캔버스에서 이미지·배치·글을 고치는 방법을 넣었습니다.

## 4차 정리 (장별 파일)

- 요청문은 `실습가이드.html`에서만 복사합니다. 장별 `프롬프트.txt`와 `현대엔지비_무료실습_16개프롬프트.txt`는 삭제했습니다.
- 장 폴더에는 실제로 쓰는 파일만 둡니다: 1장 `엔지비기업_상황자료.docx`(AI에 첨부), 3장 `근거메모_작성양식.docx`, 5장 `사업기획서_양식.docx`(새로 추가), 8장 `실습기록표.docx`. 파일이 필요 없는 2·4·6·7장 폴더는 없앴습니다.
- 요청 ① 첫 줄에 "첨부한 ‘엔지비기업_상황자료’를 먼저 읽어 줘. 첨부가 없으면 아래 설명만 사용해."를 넣었습니다.

## 3차 정리 (사례 변경)

- 가상 사례를 온라인 판매점 「한결생활」에서 무역·납품 업체 「엔지비기업」으로 바꿨습니다. 반복 문의는 거래처의 납기·견적·선적서류 문의, 서비스 제외 범위는 자동 발송·단가·납기 확정·클레임 보상 판단입니다.
- 요청문 16개, 강사 예시, 교안, HTML 가이드, 장별 프롬프트.txt에 모두 반영했습니다. 원본 PPTX 슬라이드 문구는 아직 「한결생활」입니다.

## 2차 정리 (HTML·장별 구성)

- `실습가이드.html` 하나로 모든 장을 봅니다. 장마다 할 일, 따라 하기, 요청문 복사(대괄호 칸을 채우면 내 내용이 들어간 채로 복사), 이렇게 나오면 성공 체크, 안 되면, 도구가 안 될 때 쓰는 예시가 있습니다.
- 3장에 근거 메모 입력 칸(4장 요청 ⑦로 불러오기), 8장에 실습기록표를 넣었습니다. 입력값은 그 브라우저에만 저장됩니다.
- 폴더를 `1차시/01_사업아이디어 … 2차시/08_공유피드백`으로 나누고, 장마다 `프롬프트.txt`와 해당 양식을 두었습니다.
- `먼저_읽어주세요.docx`와 `실습_시작하기.docx`는 HTML로 대체해 삭제했습니다. `수강생실습/`의 양식은 해당 장 폴더로 옮겼습니다.

## 왜 바꿨나요

| 기준 | 요청서·PPTX 교안 | 원본 패키지 |
|---|---|---|
| 1차시 주제 | AI와 **사업 아이디어** 구상 | 내부 고객 문의 개선안(사업 아이디어 아님) |
| 도구 | ChatGPT·Gemini Canvas, Perplexity, Gamma | ChatGPT 중심 + 세 도구 비교, NotebookLM |
| 입력 방식 | 요청문에 가상 사례 포함, 파일 첨부 없음 | XLSX·DOCX 첨부, 업로드 대안 TXT |
| 실습 내용 | 아이디어 → Canvas → 리서치 → 기획서 → 검토 → Gamma → 수정 → 공유 | 계산 검산(인시·비용), 선적서류 대조 시연 포함 |

## 확인한 것 / 확인하지 못한 것

- Word 문서 4종은 PDF로 렌더링해 레이아웃을 확인했습니다.
- 요청문 16개는 PPTX와 `../프롬프트집.md`의 문장 그대로입니다.
- 수강생 계정에서 실제 AI를 실행한 결과는 없습니다. 강사 예시는 실행 결과가 아닙니다.
- 3단계 강사 후보 링크(Zendesk)는 이번 작업 환경의 네트워크 제한으로 다시 열어 보지 못했습니다. 수업 전 확인이 필요합니다.
