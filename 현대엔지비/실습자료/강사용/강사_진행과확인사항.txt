강사 진행과 확인사항

과정 성격
기초 과정입니다. 목표는 "AI로 아이디어 → 문서 → 근거 → 기획서 → 발표자료"의 흐름을 쉽게 경험하는 것입니다.
시간 배분은 요청서의 기준이며, 수강생 속도에 맞춰 조절합니다. 늦어지면 「필요할 때만」 요청과 이미지 생성(선택)을 건너뜁니다.

요청서 차시 구성과 실습 단계 대응
1차시  생성형 AI로 아이디어 생성하고 리서치하기 (ChatGPT, Gemini, Perplexity)
  [20분] AI와 사업 아이디어 구상(프롬프트 엔지니어링 실습)  → 1단계  요청 ①(②)  · "좋은 요청의 네 가지" 설명
  [10분] ChatGPT Canvas 또는 Gemini Canvas 문서 작성        → 2단계  요청 ③④
  [20분] Perplexity로 리서치(프롬프트 엔지니어링 실습)       → 3단계  요청 ⑤(⑥) · 네 가지 요소 다시 확인
  [10분] 사업기획서 초안 완성                                 → 4단계  요청 ⑦
2차시  생성형 AI로 사업기획서 PPT 생성하기 (Gamma AI)
  [20분] 기획서 검토 → 최종 보고서                            → 5단계  요청 ⑧⑨(⑩)
  [10분] Gamma AI로 PPT 생성                                  → 6단계  요청 ⑪⑫
  [20분] 이미지·레이아웃·글 수정                              → 7단계  요청 ⑬⑭⑮
  [10분] 실습 결과 공유 및 피드백                              → 8단계  요청 ⑯

자료 배포
수강생: 실습가이드.html(장별 따라 하기·요청문 복사·근거 메모·실습기록표)과 장별 파일 — 1장 엔지비기업_상황자료.docx(AI에 첨부), 3장 근거메모_작성양식.docx, 5장 사업기획서_양식.docx, 8장 실습기록표.docx. 추가참고(선택)
강사용 폴더는 배포하지 않습니다. 강사작성_가상예시는 실습가이드.html 각 장의 「도구가 안 될 때 쓰는 예시」에 접혀 들어 있습니다. 쓴 단계는 「대체 실습」으로 기록하게 합니다.

도구 선택
요청서에 ChatGPT와 Gemini가 함께 있으므로 1~5단계는 둘 중 하나를 고르게 합니다. 강의 화면은 리허설한 도구 하나(기본 Gemini)로만 시연하고, 다른 도구 사용자는 같은 요청문을 쓰게 합니다.
한 사람이 단계 중간에 도구를 바꾸지 않게 안내합니다(Canvas 문서가 이어지지 않음).

수업 전 리허설 (실행 결과는 아직 확보하지 않음)
- Gemini Canvas 진입 메뉴, 문단 선택 후 요청, 「공유 및 내보내기 → Docs로 내보내기」
- ChatGPT Canvas 사용 방법(도구 메뉴 또는 "캔버스로" 요청)
- Perplexity 무료 기본 검색과 출처 링크 위치
- Gamma 무료 크레딧, 생성 전 구성 계획 화면, /ai·AI editing·Smart Layouts, Export → PowerPoint
화면 메뉴 이름은 날짜·계정에 따라 다를 수 있으니 당일 화면을 기준으로 안내합니다.

Gamma가 안 될 때 (6·7장)
1순위 미리캔버스 AI 프레젠테이션: 「월간 무료 체험 ○회 남음」 확인 → 요청 ⑫+8장 원고를 입력창에 붙임(「내용 첨부하기」는 유료) → 장수 8장 → 생성 → 다운로드. 2026-10 사용자 화면 캡처에서 무료 체험 3회 남음, 장수 6~30장, 첨부는 왕관 표시를 확인. PPT 무료 다운로드 여부는 리허설에서 확인.
2순위 Kimi 슬라이드(kimi.com): 원고 붙여 생성 → PPTX 내보내기. 무료 사용량 제한.
마지막 PowerPoint·Google Slides 직접 작성: 항상 가능. 글 수정은 Gemini 요청 ⑮로 받아 붙임.

3단계 검색이 막힐 때의 원문 후보
원본 PPTX 발표자 노트에 강사 사전 확인 후보로 적힌 링크:
https://support.zendesk.com/hc/en-us/articles/4408882663194-Getting-started-with-self-service-Part-7-Maintaining-and-improving-your-knowledge-base
FAQ 담당·검토·갱신 절차 참고용이며 수요·효과의 근거가 아닙니다. 이번 자료 정리 중에는 네트워크 제한으로 다시 열어 보지 못했으므로, 수업 전 직접 열어 확인하세요. 두 번째 자료는 수강생이 직접 찾게 합니다.

수업 중 지킬 것
- 같은 요청을 반복 생성하거나 새 계정을 만들게 하지 않습니다. 유료 가입을 요구하지 않습니다.
- 수요·가격·효과 수치를 만들지 않습니다. 모르는 것은 [가설], 못 연 원문은 「미확인」.
- 도구 기능을 못 쓴 단계는 「대체 실습」으로 기록하게 하고 완료로 쓰지 않습니다.
- 강사 예시를 수강생의 실행 결과처럼 제출하지 않게 합니다.
