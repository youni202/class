# 현대엔지비 · 생성형 AI 기초 실습 (2차시)

가상 무역·납품 업체 「엔지비기업」이 기존 강점을 살린 **신사업**을 기획합니다: 신사업 아이디어 찾기 → Canvas 기획서 → 경쟁사 벤치마킹(Perplexity) → 기획서 완성 → Gamma 발표자료 8장.

| 순서 | 파일·폴더 | 내용 |
|---|---|---|
| 01 | [01_실습가이드.html](./01_실습가이드.html) | 1~8장 따라 하기, 요청문 복사, 파일 받기, 경쟁사 메모, 실습기록표. 이 파일 하나로 실습 가능 · 온라인: https://claude.ai/artifact/J1PCi9n7oUg4XuPBJ9pP9n |
| 02 | [02_실습파일/](./02_실습파일) | 1장 회사소개(AI에 첨부), 3장 경쟁사 벤치마킹 양식, 5장 신사업기획서 양식, 8장 실습기록표 — 가이드 안 「받기」와 같은 파일 |
| 03 | [03_추가참고/](./03_추가참고) | (선택) 국내외 기업의 AI 활용 사례 읽을거리 |
| — | [captures/](./captures) | 실제 화면 캡처(`cap-01.png`~`cap-26.png`)를 넣으면 가이드의 설명용 그림이 실제 화면으로 바뀜 |
| — | [tools/](./tools) | 가이드를 다시 만드는 스크립트, 요청문 원본(`prompts.md`), 리허설 시나리오(`리허설/`) |

다시 만들기: `python3 tools/build.py` → `node tools/forms.js` → `node tools/guide.js` → `python3 tools/runbook.py`
