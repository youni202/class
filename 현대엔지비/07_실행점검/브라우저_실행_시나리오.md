# 브라우저 실행 시나리오 (엔지비기업 실습 리허설)

실습가이드의 8개 장을 **실제 로그인된 브라우저에서 처음부터 끝까지 한 번 실행**하고, 화면 캡처와 실제 결과를 남기기 위한 시나리오입니다.
사람이 직접 해도 되고, 사용자 컴퓨터에서 도는 Claude 세션(Claude 데스크톱 앱 + Chrome 연동, 또는 이 폴더에서 `claude remote-control`)에게 맡겨도 됩니다.

## Claude 세션에 맡길 때 붙여넣을 지시문

```
현대엔지비/07_실행점검/브라우저_실행_시나리오.md 를 읽고 cap-01부터 cap-26까지 순서대로 내 Chrome에서 실행해 줘.
- 이미 로그인된 내 무료 계정만 사용하고, 유료 업그레이드·결제·새 계정 만들기는 하지 마.
- 요청문은 현대엔지비/01_실습가이드.html 해당 장의 「복사할 요청」을 그대로 쓰고, [대괄호]는 바로 앞 단계의 실제 결과로 바꿔. 1장에서는 02_실습파일/1장_엔지비기업_회사소개.docx 를 첨부해.
- 각 cap마다 화면을 1280x800 정도로 캡처해 현대엔지비/captures/cap-XX.png 로 저장해. 이메일·계정명·프로필 사진은 가려.
- 결과는 현대엔지비/07_실행점검/실행기록.md 의 해당 칸에 사실대로 적어. 실행이 안 된 것은 "미실행"과 이유를 적고, 결과를 지어내지 마.
- 메뉴 이름이나 순서가 가이드와 다르면 실행기록의 "가이드와 다른 점"에 적어. 가이드 문구는 마지막에 한꺼번에 고칠게.
- 한도 안내가 뜨면 멈추고 나에게 알려 줘.
```

## 지킬 것

- 교육용 가상 사례(엔지비기업)만 입력합니다. 실제 거래처·회사 자료는 넣지 않습니다.
- 요청문은 한 번만 보냅니다. 생성 중에는 다시 보내지 않습니다.
- 「필요할 때만」 요청은 앞 결과에 해당 문제가 있을 때만 실행하고, 실행 여부를 기록합니다.
- Gamma AI 이미지·AI 편집은 크레딧이 남아 있을 때만 실행합니다. 남은 크레딧을 기록합니다.
- 캡처는 핀 번호가 가리킬 위치가 화면 안에 보이도록 찍습니다(아래 각 cap의 "화면에 보여야 할 것").

## 1장 · 신사업 아이디어  (Gemini)

요청문: `01_실습가이드.html` 1장

### cap-01 · Gemini 새 채팅 열고 회사소개 첨부

- 도구: Gemini (https://gemini.google.com)
- 할 일:
  1. gemini.google.com 접속 (수업 전 본인 Google 무료 계정으로 로그인)
  2. 사례 설명: 엔지비기업(가상 무역·납품 업체)이 기존 강점을 살린 신사업을 찾는다 — 회사 분석이 아니라 아이디어 찾기
  3. 회사소개는 AI에게 주는 배경 정보(좋은 요청의 「상황」)
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 새 채팅 버튼을 눌러 빈 대화를 연다
  2. 당일 기본 모드 확인 — 유료 모델은 고르지 않는다
  3. 「+」로 1장_엔지비기업_회사소개.docx 첨부 (안 되면 건너뜀)
- 성공 기준: 빈 채팅에 회사소개 파일이 첨부돼 있다 (첨부가 안 되면 요청문 안의 설명만으로 진행)
- 막혔을 때: 한도 안내가 뜨면 멈추고 강사 예시 카드로 읽기·선택만 진행, 대체 실습으로 기록
- 캡처 저장: `captures/cap-01.png`

### cap-02 · 요청 ① 보내고 아이디어 5개 받기

- 도구: Gemini (https://gemini.google.com)
- 보낼 요청: ①
- 할 일:
  1. 복사 버튼으로 요청 ① 전체를 복사
  2. 입력창에 붙여넣고 처음과 끝이 들어갔는지 확인 (Ctrl+V / Mac Command+V)
  3. 한 번 전송하고 화면 유지 → Teams에 「완료」 또는 「멈춘 위치」 남기기
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 요청 ①을 한 덩어리로 붙여넣기 (처음·끝 포함 확인)
  2. 전송은 한 번만 — 생성 중 재전송 금지
  3. 응답: 아이디어 5개 비교표 + 추천 아이디어 카드
- 성공 기준: 아이디어 5개의 비교표와 추천 카드가 나왔다. 수요·지불 의향은 [가설], 새 숫자 없음
- 막혔을 때: 입력 위치·전송 여부 확인. 반복 생성·새 계정 금지. 강사 예시로 내용 작성만 진행
- 캡처 저장: `captures/cap-02.png`

### cap-03 · 아이디어 고르고 카드 복사

- 도구: Gemini (https://gemini.google.com)
- 보낼 요청: ② (필요할 때만 포함)
- 할 일:
  1. 각자 해 볼 아이디어 하나를 고른다 (AI 추천과 달라도 된다)
  2. 고른 이유를 한 줄로 말해 보게 한다: 우리 강점과 어떻게 이어지나?
  3. 카드 여섯 항목만 복사해 둔다 (비교표 제외)
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 비교표: 고객·문제·제공 가치·필요 역량·준비 부담·4주 확인 질문
  2. 추천 카드 6항목: 고객·문제·해결 방법·수익 방식·활용할 강점·확인 질문
  3. 추천과 다른 아이디어를 고르면 요청 ②로 카드를 다시 받는다
- 성공 기준: 복사할 카드에 고객·해결 방법·활용할 강점과 [가설] 표시가 있다
- 막혔을 때: 추천 그대로면 ②는 실행하지 않는다
- 캡처 저장: `captures/cap-03.png`

## 2장 · Canvas 기획서  (Gemini Canvas)

요청문: `01_실습가이드.html` 2장

### cap-04 · 새 채팅에서 Canvas 선택

- 도구: Gemini (https://gemini.google.com)
- 할 일:
  1. 앞 채팅이 아닌 새 채팅에서 시작
  2. 요청 ③보다 Canvas 선택이 먼저 — 요청문만 보내면 Canvas가 열리지 않는다
  3. Gemini: 입력창 아래 「Canvas」 / ChatGPT: 「+」 → 「캔버스」 → 입력창에 Canvas 표시 확인
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 입력창 아래 도구 메뉴를 연다
  2. Canvas를 선택한다 (메뉴 이름은 당일 화면 기준)
  3. 다음 요청 ③을 붙일 입력창
- 성공 기준: 입력창에 Canvas가 선택된 상태
- 막혔을 때: Canvas 버튼이 없거나 한도에 걸리면 5장_신사업기획서_양식.docx에 카드를 옮겨 한 문단 고치기만 연습, 대체 실습으로 기록
- 캡처 저장: `captures/cap-04.png`

### cap-05 · 요청 ③ Canvas 기획서 골격 만들기

- 도구: Gemini Canvas (https://gemini.google.com)
- 보낼 요청: ③
- 할 일:
  1. 입력창에 Canvas 표시가 없으면 보내지 말고 앞 화면으로 돌아가 Canvas부터 켜기
  2. 복사 → 「아이디어 카드:」 뒤에 1장 카드 붙이기
  3. 전송 후 제목과 문서 패널이 열릴 때까지 대기
  4. 「경쟁사와 차별점」은 「조사 예정」으로 비어 있는 게 맞다 (3장에서 채움)
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 요청 ③ 붙여넣기 — 「아이디어 카드:」 뒤에 내 카드를 붙이고 1회 전송
  2. 기획서 제목과 「교육용 가상사례」 표시
  3. 소제목 7개: 사업 개요 / 고객과 문제 / 해결 방법 / 경쟁사와 차별점 / 수익 모델 / 4주 시범 / 위험과 질문
  4. 편집 가능한 문서 패널이 열렸는지 확인
- 성공 기준: 문서 패널·제목·소제목 7개·[가설] 표시. 일반 채팅 답변만 나왔다면 Canvas를 안 켜고 보낸 것 → 새 채팅에서 Canvas를 켜고 다시 보냄
- 막혔을 때: 2분 이상 막히면 강사 예시 2를 편집기에 붙여 한 문단 고치기 연습, 대체 실습 명시
- 캡처 저장: `captures/cap-05.png`

### cap-06 · 요청 ④ 「해결 방법과 제공 가치」만 고치기

- 도구: Gemini Canvas (https://gemini.google.com)
- 보낼 요청: ④
- 할 일:
  1. 고칠 문단을 드래그로 선택 → 나타나는 요청창에 붙여넣기
  2. 같은 Canvas를 유지 (새 문서 만들지 않음)
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 「해결 방법과 제공 가치」 문단만 드래그로 선택
  2. 선택 문단의 요청창에 요청 ④ 붙여넣기
  3. 다른 문단과 [가설] 표시가 그대로인지 확인
- 성공 기준: 해결 방법 문단만 세 문장(고객이 할 수 있게 되는 것 / 제공 기능 / 활용 강점)으로 바뀌었다
- 막혔을 때: 선택 요청창이 없으면 문단을 직접 고친다

### cap-08 · 요청 ⑤ 경쟁사 3곳 찾기

- 도구: Perplexity (https://www.perplexity.ai)
- 보낼 요청: ⑤
- 할 일:
  1. 아이디어 한 줄 예: "해외 거래처가 산업용 부품을 온라인으로 견적·주문하는 B2B 서비스"
  2. 긴 답변을 다 읽기보다 공식 사이트 링크를 먼저 찾는다
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 「[내 신사업 아이디어 한 줄]」을 바꿔 붙이고 한 번만 전송
  2. 경쟁사 3곳 정리 — 그대로 믿지 말고 출처로 이동
  3. 출처 링크 = 경쟁사 공식 사이트 후보
- 성공 기준: 경쟁사·유사 서비스 3곳과 각각의 출처 링크가 있다
- 막혔을 때: 결과가 엉뚱하면 아이디어 한 줄을 더 구체적으로 바꿔 한 번만 다시 묻는다
- 캡처 저장: `captures/cap-08.png`

### cap-09 · 경쟁사 공식 사이트 직접 열어 확인

- 도구: 브라우저 새 탭
- 보낼 요청: ⑥ (필요할 때만 포함)
- 할 일:
  1. 경쟁사마다: 누구를 위한 서비스인가 → 무엇을 제공하나 → 가격이 공개돼 있나
  2. AI 요약과 사이트 내용이 같은지 확인
  3. 경쟁사가 기능을 제공한다 ≠ 우리 고객이 돈을 낸다
- 화면에 보여야 할 것 (핀 번호 순서):
  1. 탭 2~3개: 경쟁사 공식 사이트
  2. 주소창 URL을 메모에 기록
  3. 서비스 이름·대상 고객 확인
  4. 주요 기능·가격 안내가 실제로 있는지 확인
- 성공 기준: 경쟁사 2곳 이상의 공식 사이트를 실제로 열었다
- 막혔을 때: 요약과 다르면 요청 ⑥(조건부) 또는 해당 내용을 [미확인]으로
- 캡처 저장: `captures/cap-09.png`

### cap-10 · 경쟁사 메모와 벤치마킹 정리
