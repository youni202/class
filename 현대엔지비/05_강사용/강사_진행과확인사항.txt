강사 진행과 확인사항

과정 성격
기초 과정입니다. 목표는 "AI로 신사업 아이디어 찾기 → Canvas 기획서 → 경쟁사 벤치마킹 → 기획서 완성 → 발표자료"의 흐름을 쉽게 경험하는 것입니다.
시간 배분은 요청서 기준이며, 수강생 속도에 맞춰 조절합니다. 늦어지면 「필요할 때만」 요청과 그림 만들기(선택)를 건너뜁니다.

사례
엔지비기업은 해외 거래처에 산업용 부품을 납품해 온 가상의 중소 무역·납품 업체입니다.
1장 회사소개는 회사 분석이 아니라, AI가 엔지비기업에 맞는 신사업 아이디어를 내도록 주는 배경 정보(좋은 요청의 「상황」)입니다.
수강생은 각자 고른 아이디어로 끝까지 진행합니다. 강사 시연·예시는 대표 아이디어 「B2B 부품 온라인 주문」으로 합니다.

요청서 차시 구성과 실습 장 대응
1차시  생성형 AI로 아이디어 생성하고 리서치하기 (ChatGPT, Gemini, Perplexity)
  [20분] AI와 사업 아이디어 구상(프롬프트 엔지니어링 실습)  → 1장  요청 ①(②) · 좋은 요청의 네 가지
  [10분] ChatGPT Canvas 또는 Gemini Canvas 문서 작성        → 2장  요청 ③④
  [20분] Perplexity로 리서치(프롬프트 엔지니어링 실습)       → 3장  요청 ⑤(⑥) · 경쟁사 찾기와 벤치마킹
  [10분] 사업기획서 초안 완성                                 → 4장  요청 ⑦
2차시  생성형 AI로 사업기획서 PPT 생성하기 (Gamma AI)
  [20분] 기획서 검토 → 최종 보고서                            → 5장  요청 ⑧⑨(⑩)
  [10분] Gamma AI로 PPT 생성                                  → 6장  요청 ⑪⑫
  [20분] 이미지·레이아웃·글 수정                              → 7장  요청 ⑬⑭⑮
  [10분] 실습 결과 공유 및 피드백                              → 8장  요청 ⑯

자료 배포
수강생: 01_실습가이드.html(장별 따라 하기·요청문 복사·파일 받기·경쟁사 메모·실습기록표). 같은 파일이 02_실습파일/ 폴더에도 있습니다 — 1장_엔지비기업_회사소개.docx(AI에 첨부), 3장_경쟁사_벤치마킹_양식.docx, 5장_신사업기획서_양식.docx, 8장_실습기록표.docx. 06_추가참고(선택)
강사용 폴더는 배포하지 않습니다. 강사작성_가상예시는 실습가이드 각 장의 「도구가 안 될 때 쓰는 예시」에 접혀 들어 있습니다. 쓴 단계는 「대체 실습」으로 기록하게 합니다.

도구 선택
요청서에 ChatGPT와 Gemini가 함께 있으므로 1~5장은 둘 중 하나를 고르게 합니다. 강의 화면은 리허설한 도구 하나(기본 Gemini)로만 시연하고, 다른 도구 사용자는 같은 요청문을 쓰게 합니다.
한 사람이 장 중간에 도구를 바꾸지 않게 안내합니다(Canvas 기획서가 이어지지 않음).

3장 경쟁사 벤치마킹 진행 요점
- 경쟁사 조사는 베끼기가 아니라 「배울 점」과 「다르게 할 점」을 찾는 것입니다. 다르게 할 점은 회사소개의 강점에서 찾게 합니다.
- AI가 정리한 경쟁사 정보는 공식 사이트를 직접 열어 확인합니다. 최소 2곳은 꼭 엽니다.
- 경쟁사가 기능을 제공한다는 것은 사실이지만, 우리 고객이 돈을 낼 것이라는 건 아직 가설입니다.
- 검색이 막히면 대표 아이디어 기준 검색어를 안내합니다: "산업용 부품 B2B 온라인 주문", "MRO 구매 플랫폼", "industrial parts B2B ordering portal". 강사가 특정 회사를 정답처럼 제시하지 않습니다.

Gamma가 안 될 때 (6·7장)
1순위 미리캔버스 AI 프레젠테이션: 「월간 무료 체험 ○회 남음」 확인 → 요청 ⑫+8장 원고를 입력창에 붙임(「내용 첨부하기」는 유료) → 장수 8장 → 생성 → 다운로드. 사용자 화면 캡처에서 무료 체험 3회 남음, 장수 6~30장, 첨부는 왕관 표시를 확인. PPT 무료 다운로드 여부는 리허설에서 확인.
2순위 Kimi 슬라이드(kimi.com): 원고 붙여 생성 → PPTX 내보내기. 무료 사용량 제한.
마지막 PowerPoint·Google Slides 직접 작성: 항상 가능. 글 수정은 Gemini 요청 ⑮로 받아 붙임.

수업 전 리허설 (실행 결과는 아직 확보하지 않음)
- Gemini 파일 첨부(docx), Canvas 진입 메뉴(요청 ③ 전에 Canvas를 먼저 켜야 함), 문단 선택 후 요청, 「공유 및 내보내기 → Docs로 내보내기」
- ChatGPT Canvas 사용 방법(입력창 「+」 → 「캔버스」를 먼저 선택. 요청문만으로는 Canvas가 열리지 않음)
- Perplexity 무료 기본 검색에서 대표 아이디어로 경쟁사 3곳과 출처 링크가 나오는지
- Gamma 무료 크레딧, 생성 전 구성 계획 화면, /ai·AI 편집·Smart Layouts, Export → PowerPoint
- 미리캔버스·Kimi 대안 경로
화면 메뉴 이름은 날짜·계정에 따라 다를 수 있으니 당일 화면을 기준으로 안내합니다.

수업 중 지킬 것
- 같은 요청을 반복 생성하거나 새 계정을 만들게 하지 않습니다. 유료 가입을 요구하지 않습니다.
- 시장 규모·매출·가격 숫자를 만들지 않습니다. 모르는 것은 [가설], 확인 못 한 경쟁사 정보는 「미확인」.
- 도구 기능을 못 쓴 단계는 「대체 실습」으로 기록하게 하고 완료로 쓰지 않습니다.
- 강사 예시를 수강생의 실행 결과처럼 제출하지 않게 합니다.
