## ① 신사업 아이디어 탐색과 아이디어 카드 (1장)

```
첨부한 ‘엔지비기업 회사소개’를 먼저 읽어 줘. 첨부가 없으면 아래 설명만 사용해.
엔지비기업은 해외 거래처에 산업용 부품을 납품해 온 가상의 중소 무역·납품 업체야. 기존 강점을 살린 신사업을 찾고 있어.
회사의 강점을 살릴 수 있는 신사업 아이디어 5개를 제안해 줘.
각 아이디어를 고객 / 해결할 문제 / 제공 가치 / 필요한 역량 / 준비 부담 / 4주 안에 확인할 질문으로 비교해 줘.
그중 가장 시작하기 쉬운 1개를 추천하고, 고객 / 문제 / 해결 방법 / 수익 방식 / 활용할 강점 / 확인 질문의 아이디어 카드로 정리해 줘.
시장 규모·매출 같은 새 숫자는 만들지 말고, 수요와 지불 의향은 [가설]로 표시해 줘.
```

## ② 내가 고른 아이디어로 카드 다시 쓰기 — (조건부) 추천과 다른 아이디어를 고르거나 카드가 막연할 때 (1장, 같은 채팅)

```
필요할 때만: 내가 고른 아이디어는 [아이디어 번호와 이름]이야.
이 아이디어로 고객 / 문제 / 해결 방법 / 수익 방식 / 활용할 강점 / 확인 질문의 카드를 다시 써 줘.
고객은 누구인지 구체적으로(업종·규모·담당자), 해결 방법은 무엇을 제공하는지 한 문장으로 써 줘.
새 숫자는 만들지 말고 수요와 지불 의향은 [가설]로 표시해 줘.
```

## ③ Canvas로 사업기획서 골격 만들기 (2장, 새 채팅 → Canvas 선택)

```
Canvas로 편집할 수 있는 신사업 기획서를 만들어 줘. 제목 아래에 ‘교육용 가상사례’라고 표시해 줘.
소제목: 사업 개요 / 고객과 문제 / 해결 방법과 제공 가치 / 경쟁사와 차별점 / 수익 모델 / 4주 시범 계획 / 위험과 확인 질문.
‘경쟁사와 차별점’은 3장에서 조사해 채울 거라 지금은 ‘조사 예정’이라고만 써 줘.
아이디어 카드: [1장에서 복사한 아이디어 카드]
확인하지 않은 내용은 [가설]로 표시하고, 새 숫자·실적은 만들지 마.
```

## ④ 「해결 방법과 제공 가치」 문단만 고치기 (2장, 같은 Canvas에서 문단 선택)

```
선택한 ‘해결 방법과 제공 가치’ 문단만 세 문장으로 고쳐 줘.
첫 문장은 고객이 무엇을 할 수 있게 되는지, 둘째 문장은 우리가 제공하는 기능이나 서비스, 셋째 문장은 엔지비기업의 어떤 강점을 활용하는지 써 줘.
다른 문단과 [가설] 표시는 그대로 두고, 새 숫자는 넣지 마.
```

## ⑤ 경쟁사·유사 서비스 찾기 (3장, Perplexity 새 검색 · 기본 검색)

```
[내 신사업 아이디어 한 줄]과 비슷한 서비스를 하는 국내외 경쟁사나 유사 서비스 3곳을 찾아 줘.
각각 회사·서비스 이름 / 대상 고객 / 주요 기능과 제공 방식 / 공개된 가격 정보(없으면 ‘미공개’) / 강점 / 약점이나 한계 / 원문 URL로 정리해 줘.
회사 공식 사이트나 공식 발표 자료를 우선해 줘.
마지막에 우리 아이디어가 배울 점 1개와 다르게 할 점 1개를 써 줘.
확인할 수 없는 내용은 ‘미확인’으로 쓰고, 시장 규모나 점유율 숫자를 새로 만들지 마.
```

## ⑥ 원문과 다시 대조하기 — (조건부) AI 요약이 원문과 다를 때 (3장, 같은 검색)

```
필요할 때만: 앞에서 정리한 경쟁사 정보를 원문과 다시 대조해 줘.
각 내용이 원문 어디에 있는지 짚고, 원문에서 확인되지 않는 내용은 지우거나 [미확인]으로 바꿔 줘.
더 정확한 공식 자료가 있으면 회사·서비스 / 내용 / URL로 알려 줘. 숫자는 새로 만들지 마.
```

## ⑦ 경쟁사 비교를 넣어 기획서 초안 완성 (4장, 2장의 같은 Canvas)

```
아래 경쟁사 메모로 같은 Canvas 기획서를 2쪽 안팎 초안으로 완성해 줘. 소제목과 ‘교육용 가상사례’ 표시는 유지해 줘.
‘경쟁사와 차별점’에는 경쟁사 2~3곳과 우리 아이디어를 대상 고객·주요 기능·강점·약점으로 비교한 표를 넣고, 차별점은 [가설]로 표시해 줘.
‘4주 시범 계획’은 준비 → 시범 → 관찰 → 평가로 쓰고, 고객 반응·유료 이용 의향을 어떻게 확인할지 넣어 줘.
경쟁사 정보에는 출처를 붙이고, 새 숫자·실적은 만들지 마. 마지막에 4주 시범 검토를 요청하는 문장을 넣어 줘.
경쟁사 메모: [3장에서 직접 확인한 경쟁사 메모]
```

## ⑧ 검토만 받기 (5장, 같은 Canvas)

```
지금 기획서를 검토만 해 줘. 아직 Canvas는 고치지 마.
① 고객과 문제가 구체적인가 ② 해결 방법이 문제와 이어지는가 ③ 경쟁사 비교가 출처에 근거하는가 ④ 차별점과 수익 모델이 [가설]로 표시됐는가 ⑤ 4주 시범 계획이 실제로 해 볼 만한가 ⑥ 엔지비기업의 강점과 이어지는가를 살펴봐 줘.
중요한 것 최대 5개를 ‘문제 문장 / 이유 / 고칠 방향’으로 보여 줘. 없는 문제를 만들지 말고, 내가 고를 때까지 기다려 줘.
```

## ⑨ 고른 것만 고치기 (5장, 같은 Canvas)

```
아래에서 내가 고른 것만 지금 Canvas에 반영해 줘.
고르지 않은 문단, 출처, [가설] 표시, ‘교육용 가상사례’ 표시는 그대로 둬. 새 숫자·실적은 넣지 마.
고친 뒤 바뀐 문장과 바꾼 이유만 짧게 알려 줘.
내가 고른 것: [검토 결과의 번호와 내가 정한 고칠 방향]
```

## ⑩ 단정한 문장 고치기 — (조건부) 수요·차별점을 사실처럼 썼을 때 (5장, ⑨ 대신)

```
필요할 때만: 기획서에서 고객이 반드시 쓸 것이라거나 경쟁사보다 확실히 낫다고 단정한 문장만 찾아서 고쳐 줘.
수요와 지불 의향은 ‘아직 확인하지 않은 가설’로, 차별점은 ‘4주 시범으로 검증할 제안’으로 바꿔 줘.
다른 문단과 출처는 그대로 두고, 바뀐 문장만 알려 줘.
```

## ⑪ 발표 원고 8장 만들기 (6장, 같은 Canvas)

```
검토를 마친 기획서만으로 8장 발표 원고를 따로 써 줘. 기획서 본문은 바꾸지 마.
순서: ①사업 제안 ②고객과 문제 ③해결 방법 ④경쟁사 비교와 차별점 ⑤수익 모델 ⑥4주 시범 계획 ⑦확인할 지표와 위험 ⑧결정 요청.
각 장은 짧은 제목 1개, 핵심 문장 1개, 본문 최대 3줄로 써 줘. 출처와 [가설] 표시, ‘교육용 가상사례’ 표시는 유지하고 새 숫자는 넣지 마.
```

## ⑫ Gamma로 발표자료 8장 만들기 (6장, Gamma 새로 만들기 입력창)

```
아래 확정 원고로 한국어 발표자료 8장을 만들어 줘. 먼저 원고 순서대로 8장 구성 계획을 보여 줘.
한 장에 핵심 하나, 큰 글자와 짧은 문장으로 써 줘. 처음에는 글과 기본 배치만 만들고 이미지는 새로 만들지 마.
원고의 내용·출처·[가설] 표시를 유지하고, 새 조사·주장·숫자나 실제 회사 로고는 추가하지 마. ‘교육용 가상사례’라고 표시해 줘.
확정 원고: [6장에서 받은 8장 원고 전체]
```

## ⑬ 3장 그림 만들기 — (조건부) Gamma 크레딧이 있을 때만 (7장, 3장에서 `/ai`)

```
[내 서비스 한 줄 설명]을 보여 주는 단순한 평면 일러스트를 만들어 줘.
고객이 서비스를 쓰는 장면이 한눈에 보이게, 밝은 배경에 파랑·회색 위주로, 가로형 발표자료에 맞게 해 줘.
읽을 수 있는 글자·숫자·실제 회사 로고는 넣지 말고, 이미 완성된 실제 서비스 화면처럼 보이지 않게 해 줘.
그림만 만들고 슬라이드 글과 배치는 바꾸지 마.
```

## ⑭ 3장 배치만 바꾸기 (7장, 3장 선택 · AI 편집 또는 직접)

```
선택한 3장 ‘해결 방법’ 카드만 2단으로 바꿔 줘. 왼쪽에는 우리가 제공하는 기능, 오른쪽에는 그림(없으면 경쟁사 대비 차별점)을 놓아 줘.
기존 제목·문장·출처·[가설] 표시는 바꾸거나 지우지 말고, 다른 카드는 그대로 둬.
```

## ⑮ 8장 결정 요청 글만 고치기 (7장, 8장 글 선택 · AI 편집 또는 직접)

```
선택한 8장 ‘결정 요청’의 글만 제목 한 줄과 본문 두 문장으로 짧게 고쳐 줘.
‘4주 동안 작은 규모로 시범 운영해 고객 반응과 유료 이용 의향을 확인하자’는 요청이 분명히 보이게 해 줘.
확인되지 않은 성공·매출 효과는 말하지 말고, 출처와 [가설] 표시는 유지해 줘. 그림·배치·다른 카드는 바꾸지 마.
```

## ⑯ 받은 질문으로 한 문장 고치기 — (조건부) 질문·피드백을 받았을 때 (8장, 같은 Canvas)

받은 질문: [받은 질문이나 피드백]
