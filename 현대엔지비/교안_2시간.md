## 1. 교육 목표

1. 아이디어 비교 → 기획 문서 → 근거 조사 → 검토·수정 → 발표자료 → 공유 피드백까지 **하나의 사례를 끊김 없이** 진행한다.
2. AI가 만든 문장을 그대로 믿지 않고 **원문을 직접 열어 대조**한다.
3. **확인한 사실**과 **검증할 사업 가설**을 구분해 표시한다.
4. 단계마다 새 파일을 만들지 않고 **같은 Canvas 문서**를 계속 고친다.

## 2. 진행 원칙 (강사 공통 규칙)

- **한 번에 한 동작.** 강사가 한 동작을 보여 주고, 수강생이 같은 동작을 따라 한다. 따라 하는 동안 강사는 설명을 멈추고 화면을 유지한다.
- **프롬프트는 한 덩어리로 복사해 한 번만 전송.** 생성 중 추가 전송·반복 생성·새 계정 만들기 금지.
- **결과 문장·디자인이 같을 필요는 없다.** 필수 항목 · 문서 상태 · 확인 행동을 기준으로 완료를 판단한다.
- **새 수치·실적·시장 규모를 만들지 않는다.** 수요·지불 의향·가격·효과는 모두 `[가설]`.
- **서비스 범위 고정:** 담당자가 검토한 뒤 답변. 자동 발송·주문 조회·환불·보상 판단은 제외.
- **조건부(필요할 때만) 프롬프트 4개**(8·18·28·43장)는 해당 문제가 실제 있을 때만 실행한다. 횟수 채우기용 실행 금지.
- **실제 고객·기밀 파일 사용 금지.** 제공된 가상 사례만 사용한다.
- **대기 멘트(공통):** "지금은 제가 다음 화면으로 넘어가지 않겠습니다. 각자 현재 행동을 마치고, 준비되면 Teams 채팅에 *완료*를 남겨 주세요. 아직이면 *멈춘 위치*만 알려 주세요."
- **미실행 항목 기록:** 도구 기능을 실행하지 못한 경우 "미완료·대체 실습"으로 기록하고 완료로 쓰지 않는다.

## 8. 원본 자료 확인 시 발견한 사항 (보완 권장)

- 슬라이드 6: 노트 "4분 드립니다" ↔ 5분 구간(4분 실습 + 1분 확인)이라 합산은 맞음.
- 조건부 슬라이드(18, 28)는 별도 시간이 없고 앞뒤 구간 안에서 쓴다. 본 교안의 순서표에도 그렇게 표기함.
- 슬라이드 17: 화면은 "원문당 4분", 노트는 "3분 대조+1분 확인"으로 표현이 다름(원문당 4분으로 통일해 사용).
