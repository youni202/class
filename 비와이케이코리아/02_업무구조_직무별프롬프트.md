# 비와이케이코리아 직무별 Canva 프롬프트

> 교육용 자료입니다. [ ] 안을 내 업무로 바꿔 쓰고, 실제 고객사명·처방·가격은 넣지 않습니다.

## 업무 구조

### 회사와 사업 구조(공개 자료 기준)

- BYK는 독일 ALTANA 그룹의 특수화학 회사이고, 비와이케이코리아는 한국 법인입니다. 도료·잉크·플라스틱용 첨가제와 함께 퍼스널케어(화장품)용 첨가제를 다룹니다.
- 화장품 분야에서는 완제품 브랜드가 아니라 원료 공급사입니다. 점토 기반 레올로지 첨가제(OPTIGEL 계열), 천연 벤토나이트 기반 PURABYK 계열처럼 제형의 점도·흐름·침전 방지·사용감을 돕는 원료가 중심입니다.
- 세부 조직·담당 범위는 회사마다 다르므로 오늘은 아래 6개 업무로 나눠 생각합니다. 실제 조직명은 현장에서 확인합니다.

### 원료가 고객에게 가는 흐름

- ① 기술영업이 브랜드사·ODM사의 신제품 기획 정보를 파악 → ② 응용기술(랩)이 제형 적용 시험·처방 가이드 지원 → ③ RA가 INCI명·원료 규격·각국 규제·인증 서류 대응 → ④ 고객서비스·SCM이 샘플·주문·재고·통관 처리 → ⑤ 마케팅이 세미나·전시회·뉴스레터로 원료 알리기 → ⑥ 경영지원이 사내 공지·교육·보고 지원.
- 고객 쪽 독자도 다양합니다: 제형 연구원(기술 근거), 구매(공급 안정성·리드타임), 품질·RA(규격서·인증), 브랜드 마케터(콘셉트·트렌드 키워드).

### 직무별로 Canva로 자주 만드는 자료

- 기술영업: 원료 소개 원페이저, 고객 미팅용 제안 슬라이드, 방문 후 요약 카드
- 응용기술(랩): 제형 적용 결과 비교표, 처방 가이드 인포그래픽, 랩 시연 안내
- RA: 규제 변경 요약 카드, 서류 요청 체크리스트, 국가별 규제 비교 인포그래픽
- 마케팅: 세미나·전시회 포스터, 트렌드 카드뉴스, 뉴스레터 배너
- 고객서비스·SCM: 샘플 요청 절차 안내, 리드타임·통관 안내문, 출하 일정 공지
- 경영지원(HR·재무·총무): 사내 공지, 온보딩 자료, 행사 안내, 월간 보고 요약
