## 회사 업무 구조 (공개 자료 기준, 세부 조직은 현장 확인)
- BYK(독일 ALTANA 그룹 특수화학)의 한국 법인, 경기 성남
- 화장품 분야: 완제품이 아니라 **퍼스널케어용 첨가제(원료)** 공급 — OPTIGEL(점토 기반 레올로지), PURABYK(천연 벤토나이트 기반)
- 적용 제형: 스킨케어·선케어, 헤어케어·스타일링, 데오도란트, 색조, 클렌징
- 고객: 화장품 브랜드사, ODM·OEM사의 제형 연구원·구매·품질·RA
- 직무 6개: 기술영업 · 응용기술(랩) · RA · 마케팅 · 고객서비스·SCM · 경영지원
