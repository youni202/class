# 비와이케이코리아 Canva 실습 안내

> 비와이케이코리아는 화장품 완제품이 아니라 화장품에 들어가는 원료(퍼스널케어용 첨가제)를 공급합니다.
> 오늘 디자인의 독자는 소비자가 아니라 브랜드사·ODM사의 제형 연구원, 구매, 품질·RA 담당자입니다.
> 모든 원료명·수치·고객사는 교육용 가상 자료이며, 실제 BYK 로고·공식 브랜드 자산은 사용하지 않습니다.

1. 직무별 프롬프트 카드 (내 업무에 맞춘 Canva 프롬프트)

3. 원료 소개 원페이저 · 제형 기술 세미나 포스터 (A4 세로)
4. 원료 소개 카드뉴스 5장 (1080×1080)
5. ODM 고객 사례 공유 프레젠테이션 7장 (16:9)
6. 샘플·서류 요청 절차 인포그래픽 1장

## 디자인 프롬프트 공식
[목적] 무엇을 하게 할지 / [독자] 누가 보는지 / [형식] 크기·분량·구성 / [스타일] 색상·분위기·금지 표현 / [원고] 붙여 넣은 내용만 사용

## 화장품 원료 자료에서 꼭 지킬 것
- 원료가 미백·주름 개선·자외선 차단 효능을 직접 내는 것처럼 쓰지 않기 → "제형 안정성·점도·사용감에 도움"처럼 역할 중심
- 인증(비건·천연 유래·할랄 등) 보유 여부는 RA 확인 전 단정하지 않기
- 실제 고객사명·처방(배합비)·가격은 넣지 않기

## 무료 계정 대체 경로
- 브랜드 키트 → 색상 HEX 코드 직접 입력
- 배경 제거 → 단색 배경 이미지 사용
- 매직 스위치 → 새 디자인 만들고 복사·붙여넣기
- Canva AI 사용량 소진 → 템플릿 검색 후 문구만 원고로 교체

## 마지막 확인
- 원고에 없는 수치·인증·고객사·효능 표현을 지웠는가
- AI 이미지가 실제 브랜드 제품·로고·실존 인물처럼 보이지 않는가
- 결과물을 PDF·PNG·PPTX로 내려받았는가
- Padlet 내 섹션(이름_업무)에 결과물·나만의 프롬프트·적용 업무를 올렸는가
