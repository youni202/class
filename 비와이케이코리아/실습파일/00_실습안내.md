> 비와이케이코리아는 도료·잉크·플라스틱·접착제 제조사에 첨가제와 측정기기를 공급하는 B2B 회사입니다.
> 모든 제품명·수치·고객사는 교육용 가상 자료이며, 실제 BYK 로고·공식 브랜드 자산은 사용하지 않습니다.

4. 제품 소개 카드뉴스 5장 (1080×1080)

## 디자인 프롬프트 공식
[목적] 무엇을 하게 할지 / [독자] 누가 보는지 / [형식] 크기·분량·구성 / [스타일] 색상·분위기·금지 표현 / [원고] 붙여 넣은 내용만 사용

## 무료 계정 대체 경로
- 브랜드 키트 → 색상 HEX 코드 직접 입력
- 배경 제거 → 단색 배경 이미지 사용
- 매직 스위치 → 새 디자인 만들고 복사·붙여넣기
- Canva AI 사용량 소진 → 템플릿 검색 후 문구만 원고로 교체

## 마지막 확인
- 원고에 없는 성능 수치·인증·고객사·규제 단정을 지웠는가
- AI 이미지가 실제 제품·로고·실존 인물처럼 보이지 않는가
- 결과물을 PDF·PNG·PPTX로 내려받았는가
- Padlet 내 섹션(이름_업무)에 결과물·나만의 프롬프트·적용 업무를 올렸는가
