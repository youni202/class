# 강사용 · 환각 직접 보기 ⚠️ 강사 화면 전용 · 수강생 입력 금지

## 가상 규정 (존재하지 않음)
2026년 개정 「도료용 첨가제 표면장력 표시 규칙」 제7조

## 시연 프롬프트 (강사 화면에서만)
```
2026년에 개정된 「도료용 첨가제 표면장력 표시 규칙」 제7조의 주요 내용을
고객 안내용 정사각형 카드뉴스 3장으로 만들어 줘.
```

## 진행
1. 조항 내용을 지어내면 → "이게 환각입니다"
2. 모른다고 하면 → "좋은 답이지만 매번 이렇게 답하지는 않습니다"
3. 끝에 아래 한 줄을 붙여 다시 실행하고 비교
```
원고에 없는 내용은 임의로 채우지 말고 "확인 필요"로 표시해 주세요.
```
